## 1. Назначение

Многопользовательский Telegram-бот для заучивания английских слов из Oxford 3000. Бот присылает слова по расписанию в течение дня, показывает перевод (скрытый до нажатия), определение, пример, коллокации, синонимы и антонимы, и собирает обратную связь через кнопки **«Знаю» / «Не знаю»** для управления интервальным повторением.

## 5. Формат сообщения

**Основной вид (перевод заблюрен как спойлер Telegram — `||текст||`):**

```
apple - ||яблоко||

📖 a round fruit with red, yellow, or green skin...
✍️ I ate an apple for breakfast.
🔗 a green apple, apple pie
🟰 —
↔️ —
```

**Правила:**
- `Word - ||Russian Translation||` — всегда первой строкой. Перевод скрыт спойлером, пользователь открывает тапом.
- `📖 Definition` — только если поле не пустое.
- `✍️ Example Sentence` — только если не пусто.
- `🔗 Collocations` — если пусто, выводить `—` (как в примере).
- `🟰 Synonyms` — если пусто, `—`.
- `↔️ Antonyms` — если пусто, `—`.
- Часть речи и Related Forms — не выводятся в основном формате (по ТЗ v2), но **хранятся в БД** и используются для фильтра.
- Кнопки под сообщением: `[✅ Знаю] [❌ Не знаю]` (inline).

**Режим «сначала слово, потом перевод»:**
- Первое сообщение содержит только `Word` и кнопку `[Показать]`. После нажатия сообщение редактируется на полный формат с кнопками `[✅ Знаю] [❌ Не знаю]`.
- Спойлер `||...||` в этом режиме не используется — перевод появляется по кнопке.

**Режим «всё сразу»:**
- Сразу полный формат со спойлером и кнопками.

**Пустые поля:** не выводить строку вообще (кроме `🔗`, `🟰`, `↔️` — там `—`).

## 6. Логика интервального повторения (SRS)

Фиксированная таблица этапов:

| Этап | Интервал до следующего показа |
|------|------------------------------|
| 0 (новое) | в очередь на сегодня |
| 1 | 1 день |
| 2 | 3 дня |
| 3 | 7 дней |
| 4 | 14 дней |
| 5 | 30 дней |
| 6 (learned) | 90 дней |

**Обработка кнопок:**
- **«Знаю»** → `stage += 1`, `next_review_at = now + interval[stage]`, `times_correct += 1`. При достижении этапа 6 статус `learned`.
- **«Не знаю»** → `stage = 0`, `next_review_at = today (ближайшее окно)`, `times_wrong += 1`.
- Ответ фиксируется один раз: повторное нажатие на то же сообщение игнорируется (кнопки удаляются после ответа).

**Освежение выученных слов:**
- Слова со статусом `learned` **не входят** в ежедневный лимит слов.
- Раз в 90 дней (этап 6) они попадают в отдельную очередь «освежения». Такие повторы **не расходуют** дневной лимит новых/изучаемых слов.
- Если пользователь отвечает «Не знаю» на освежении — слово возвращается на этап 0 и снова считается изучаемым.

## 7. Планировщик

- Один `AsyncIOScheduler` на всё приложение.
- Для каждого пользователя — своя «зона» расписания, рассчитывается от его `timezone` и `window_start/window_end`.
- Слова дня распределяются равномерно по окну: `interval = (end - start) / words_per_day`.
- Пример: 10 слов с 09:00 до 21:00 → каждые 72 минуты.
- Учитывать паузу (`/pause`).
- **Никаких напоминаний**, если пользователь не ответил — просто следующее слово по расписанию.
- При старте бота — восстановление расписаний из БД (на случай перезапуска).
- Если слово дня не было доставлено (бот был выключен) — не «догонять» задним числом, просто продолжить с текущего момента.

## 8. Модель данных (SQLite)

**users**
- `id` PK
- `telegram_id` UNIQUE
- `timezone` (IANA-строка)
- `words_per_day` INT DEFAULT 10
- `window_start` TEXT (HH:MM)
- `window_end` TEXT (HH:MM)
- `paused` BOOL DEFAULT 0
- `reveal_mode` TEXT (`spoiler` | `on_button`)
- `pos_filter` TEXT (JSON-массив или `all`)
- `created_at` DATETIME

**user_settings** (чекбоксы полей)
- `user_id` FK
- `show_definition`, `show_example`, `show_pos`, `show_related`, `show_synonyms`, `show_antonyms`, `show_collocations` BOOL

**words**
- `id` PK
- `word` TEXT UNIQUE
- `definition`, `russian_translation`, `example`, `part_of_speech`, `related_forms`, `synonyms`, `antonyms`, `collocations` — TEXT NULL

**user_words**
- `id` PK
- `user_id` FK, `word_id` FK, UNIQUE(user_id, word_id)
- `stage` INT DEFAULT 0
- `status` TEXT (`new` | `learning` | `learned`)
- `next_review_at` DATETIME NULL
- `last_reviewed_at` DATETIME NULL
- `times_correct` INT DEFAULT 0
- `times_wrong` INT DEFAULT 0
- `is_refresh` BOOL DEFAULT 0

**delivery_log**
- `id`, `user_id`, `word_id`, `sent_at`, `answered_at` NULL, `answer` NULL (`know` | `dont_know`)
